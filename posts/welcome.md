# Welcome to My Blog

This is a **minimal, modern blog** built with Next.js, styled with Tailwind CSS, and ready for deployment on Vercel.

## Features

- 📝 Write posts in Markdown
- 🎨 Clean white-black design
- ⚡ Auto-deploy on push to GitHub
- 🚀 Optimized for Vercel hosting

## How to Write Posts

Simply add `.md` files to the `posts/` directory with front matter:

```markdown
---
title: "Your Post Title"
date: "2025-01-15"
excerpt: "A brief description"
---

Your content here...
```

## Markdown Support

You can use all standard Markdown features:

- Lists (like this one)
- **Bold** and *italic* text
- [Links](https://nextjs.org)
- Code blocks
- And more!
