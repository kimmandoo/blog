# 볼드 텍스트 테스트 (Bold Text Test)

이 포스트는 마크다운에서 볼드 텍스트가 제대로 렌더링되는지 테스트합니다.

## 기본 테스트 (Basic Tests)

1. **ff** 텍스트 볼드
2. **FF** 대문자 볼드
3. **Ff** 혼합 케이스
4. **hello world** 일반 볼드

## 문맥 내 테스트 (Context Tests)

이것은 **ff** 를 포함한 문장입니다.

문장 시작 **ff** 그리고 계속됩니다.

**ff** 로 시작하는 문장.

끝에 오는 경우 **ff**

## 구두점 테스트 (Punctuation Tests)

- **ff**, 쉼표와 함께
- **ff**. 마침표와 함께
- **ff**! 느낌표와 함께
- **ff**? 물음표와 함께
- (**ff**) 괄호 안
- [**ff**] 대괄호 안

## 다른 마크다운과 함께 (With Other Markdown)

### 헤딩에서 **ff** 테스트

리스트 항목:
- 첫 번째 항목 **ff**
- 두 번째 항목 **test**
- 세 번째 항목 **bold text**

코드와 함께: `code` **ff** 텍스트

링크와 함께: [링크](/) **ff** 텍스트

## 복합 테스트 (Complex Tests)

***ff*** (볼드와 이탤릭)

****ff**** (더블 강조)

**ff** **test** **multiple** (여러 볼드)

## 영문 테스트 (English Tests)

The **ff** pattern should be bold.

This is a test with **ff** in the middle.

Multiple **ff** and **test** and **words** should all be bold.

Testing **ftp**, **file**, **http** (protocol-like words).

## 결론 (Conclusion)

모든 **ff** 패턴이 볼드로 올바르게 렌더링되어야 합니다.

볼드 텍스트는 일반 텍스트보다 **더 두껍고 진하게** 표시됩니다.
